Projects

Learning to Push: Deep Reinforcement Learning for Robotic Object Alignment on Tabletop Surfaces
Technologies: Stable-Baselines3, MuJoCo, Jax, SAC, HER, PyTorch
  • Currently developing a goal-conditioned deep reinforcement learning pipeline in MuJoCo/Gymnasium to solve the sparse-reward, complex-contact problem of planar object pushing. The solution leverages Soft Actor-Critic (SAC) with Hindsight Experience Replay (HER) to manage the sparse reward landscape, using an 8D state vector (with [sin(θ),cos(θ)] angle representation) and a 2D velocity action space ([vx​,vy​]). The objective is to achieve a final pose accuracy of < 2cm position error and < 5° orientation error and to systematically evaluate the policy's zero-shot generalization to unseen geometries.
Trajectory Optimization and Control for Free-Floating Space Manipulators
Technologies: SPART, MuJoCo, JAX, skrl
  • Engineering a physics-informed Deep Reinforcement Learning (RL) pipeline to solve the optimal end-effector 'place' task (A-to-B) for a high-dimensional, free-floating space manipulator. This approach tackles the complex, non-linear system dynamics by analytically deriving them with SPART and integrating them into a high-fidelity MuJoCo "free-space" simulation. A DRL agent is then being trained using the skrl library (JAX backend) to learn an optimal policy that achieves this placement goal, with its performance (success rate, runtime) benchmarked against a simplified, kinematics-only baseline.
Optimal Motion Planning for UR5-Based Steering Wheel Installation
Technologies: C++, UR5e, MoveIt2, Motion Planning, FLANN
  • Engineered a custom moveit_core planner plugin for ROS 2, implementing the Expansive Space Trees (EST) algorithm in C++. The planner's expansive strategy was driven by a roulette wheel selection mechanism to bias node expansion towards high-weight, unexplored regions. New states were generated using normal distribution sampling around selected nodes, and a k-d tree was implemented for efficient nearest-neighbor queries within the 6-DOF configuration space. The system was fully integrated with a UR5e robot, leveraging MoveIt's PlanningScene for state validation and collision-checking, and published visualization_msgs for real-time tree and trajectory visualization in RViz

Jackal Mobile Robot State Estimation
Technologies: Extended Kalman Filter, GPS/IMU, Sensor Fusion, ROS2, Geodetic Transformations
  • Developed a real-time Extended Kalman Filter (EKF) for 6-DOF robot localization by implementing nonlinear system dynamics and measurement models to fuse GPS/IMU data. The algorithm, which integrated geodetic coordinate transformations and adaptive noise covariance matrices, achieved 0.5-meter positioning accuracy on uneven terrain (30° slopes) and reduced position drift from 5m to 0.3m, all while maintaining a 10Hz update rate for autonomous navigation
Manipulation of UR5 Robotic Arm
Technologies: UR5, MATLAB, Inverse Kinematics, Analytical IK, Resolved-Rate, Jacobian Transpose
  • Engineered a comparative trajectory tracking framework in MATLAB for a UR5 manipulator to execute a rotation-invariant, multi-segment Cartesian "place-and-draw" task. The framework benchmarked three distinct kinematic controllers: (1) a full Analytical IK solver, derived from DH parameters and Paden–Kahan subproblems with optimal selection from 8 solutions; (2) a Resolved-Rate controller (Jacobian-based); and (3) a Jacobian Transpose controller. Robustness was achieved by incorporating manipulability-based singularity avoidance and tuning controller gains (K) and time steps (Δt) for stable, high-fidelity path tracking
